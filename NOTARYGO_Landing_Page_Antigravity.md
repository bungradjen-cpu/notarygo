# 27. CRITICAL SAAS PAYMENT RULE

Landing page checkout hanya menyelesaikan:

```text
PRICING
→ CHECKOUT
→ PAYMENT
```

Jangan menganggap iframe success page sebagai sumber kebenaran untuk aktivasi subscription.

Correct architecture:

```text
Customer Pays
↓
Mayar Payment Event / Webhook
↓
Backend Verify
↓
Idempotency
↓
Map Plan
↓
Update Subscription
↓
ACTIVE
↓
Activate Entitlements
↓
Onboarding
```

**Browser redirect tidak boleh mengaktifkan subscription.**

Jika webhook belum tersedia/terkonfigurasi:

laporkan dengan jelas:

```text
CHECKOUT UI: VERIFIED
MAYAR PAYMENT: [STATUS]
WEBHOOK ACTIVATION: NOT CONFIGURED
```

Jangan membuat fake activation.
